# FAR Calendar predictions

The published record behind the OUR CALL column on [faractionradar.com/calendar](https://www.faractionradar.com/calendar).

- `predictions.jsonl`: every call, appended when it is made, before the release.
- `reports/`: the report for each call.

Every call stays on the record, hits and misses. The git history time-stamps each one.

Research data, not investment advice.
